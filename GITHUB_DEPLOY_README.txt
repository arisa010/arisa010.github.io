ARISSA — GITHUB PAGES DEPLOYMENT

1. Unzip this file. Open the extracted folder.
2. Create a public GitHub repository named YOURUSERNAME.github.io (substitute your GitHub username).
3. Upload the CONTENTS of this folder, not the ZIP and not the enclosing folder.
   index.html must be in the repository root, next to script.js, styles.css, etc.
4. In repository Settings > Pages, select Deploy from a branch, main, /(root).
5. Wait for GitHub Pages to publish and test the website.
6. Once purchased, add arissay.com in Settings > Pages > Custom domain.
   Then configure the DNS at the domain registrar using current GitHub Pages docs.
7. To edit: change the gallery definitions in portfolio-data.js and/or assets,
   adjust styles.css for design and script.js for text and contact. Commit and
   GitHub Pages should republish.
